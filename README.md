# Front-end de Wacdo

L'objectif de ce projet est de développer l'interface Front-end de l'application Wacdo. Il permet au clients de passer des commandes sur les bornes numériques. 


## Technologies utilisées
- HTML(structure)
- SASS (mise en forme)
- Javascript (interaction)


## Fonctionnalités principales
- [x] Commander à emporter ou sur place 
- [x] Choisir parmis les différentes catégories
- [x] Choisir les options des menus et autres produits
- [x] Ajouter des produits au panier et voir les éléments sélectionnés
- [x] Modifier le panier et supprimer des produits
- [x] Finaliser la commande ou abandonner 
- [x] Indiquez le numéro de chevalet
